The Geometry and GeometryBuilder systems provide CPU-side mesh construction and GPU upload utilities for NullGraph. Together they define vertex/index data, GPU buffer ownership, and procedural mesh generation workflows.

Geometry (Class)

Represents a renderable mesh containing vertex data, index data, layout information, and optional uploaded GPU buffers.

The class acts as a bridge between CPU-side mesh data and GPU-side WebGPU buffers.

Constructor

new Geometry(layout, vertices, indices)

Creates a new geometry container.

  • layout (VertexLayout):
    The vertex memory layout describing how the vertex buffer is structured.
    • ```
  • vertices (Float32Array):
    Flat interleaved vertex data array.
  • indices (Uint16Array | Uint32Array):
    Index buffer data defining triangle connectivity.
    • ```

Public Properties

  • layout: VertexLayout
    The vertex layout describing the structure of each vertex.
    • ```
  • vertices: Float32Array
    Raw CPU-side vertex buffer data.
  • indices: Uint16Array | Uint32Array
    Raw CPU-side index buffer data.
  • vertexBuffer: GPUBuffer | null
    The uploaded GPU vertex buffer.
    null until upload() is called.
  • indexBuffer: GPUBuffer | null
    The uploaded GPU index buffer.
    null until upload() is called.
    • ```

GPU Upload

upload(engine)

Uploads the geometry data to GPU memory using the engine's BufferManager.

  • engine (NullGraph):
    The engine instance providing access to GPU buffer utilities.
    • ```
  • Returns: void
    • ```

Behavior

  • Creates a GPU vertex buffer from the internal vertex data.
  • Creates a GPU index buffer from the internal index data.
  • Stores the generated buffers internally for rendering use.

Resource Cleanup

destroy()

Destroys the GPU buffers associated with this geometry and releases their references.

  • Returns: void

Behavior

  • Calls GPUBuffer.destroy() on both vertex and index buffers.
  • Safely resets internal references to null.
  • Prevents accidental reuse of destroyed GPU resources.

VertexData (Interface)

Defines a single vertex entry used by GeometryBuilder.

Properties

  • position: [number, number, number]

GeometryBuilder (Class)

A lightweight procedural mesh construction utility for generating interleaved vertex and index data arrays.

Useful for dynamically building primitive meshes, procedural terrain, debug geometry, or imported mesh data.

Constructor

new GeometryBuilder(layout)

Creates a new geometry builder using the specified vertex layout.

  • layout (any):
    The target vertex layout definition used during mesh generation.

Public Properties

  • vertices: number[]
    Dynamic array storing packed vertex data.
    • ```
  • indices: number[]
    Dynamic array storing generated indices.
    • ```

Vertex Construction

addVertex(data)

Adds a vertex to the mesh and returns its generated index.

  • data (VertexData):
    The vertex attributes to append.
    • ```
  • Returns: number
    • ```

Behavior

  • Appends position data to the internal vertex array.
  • Appends normals if provided.
  • Uses a default normal of (0, 1, 0) if omitted.
  • Appends UV coordinates if provided.
  • Returns the generated vertex index.

Notes

  • The current implementation assumes a layout compatible with:
    • Position
    • Normal
    • UV
    • ```
  • Color handling exists in the interface but is not currently written into the vertex stream.
    • ```

Triangle Construction

addTriangle(a, b, c)

Adds a triangle face to the mesh index buffer.

  • b (number): Second vertex index.
  • c (number): Third vertex index.
    • ```
  • Returns: void
    • ```

Mesh Finalization

build()

Converts the accumulated vertex/index arrays into typed arrays ready for engine usage.

  • Returns: 
    {
    v: Float32Array,
    i: Uint16Array,
    vertexBuffer: Float32Array,
    indexBuffer: Uint16Array,
    layout: any
}

Behavior

  • Creates GPU-ready typed arrays from accumulated mesh data.
  • Returns both shorthand aliases (v, i) and compatibility fields (vertexBuffer, indexBuffer).
  • Preserves the original layout reference.

Typical Workflow

const builder = new GeometryBuilder(StandardLayout);

const a = builder.addVertex({
    position: [0, 0, 0],
    normal: [0, 1, 0],
    uv: [0, 0]
});

const b = builder.addVertex({
    position: [1, 0, 0],
    normal: [0, 1, 0],
    uv: [1, 0]
});

const c = builder.addVertex({
    position: [0, 1, 0],
    normal: [0, 1, 0],
    uv: [0, 1]
});

builder.addTriangle(a, b, c);

const meshData = builder.build();

The resulting typed arrays can then be passed into a Geometry instance and uploaded to the GPU.
