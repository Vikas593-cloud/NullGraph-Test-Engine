The Camera class handles the mathematical generation of the 3D view and perspective matrices. It is designed for zero-copy WebGPU integration, packing the matrix and camera position directly into a contiguous Float32Array.

Public Properties

  • projectionMatrix: mat4
    The computed perspective projection matrix.
  • viewMatrix: mat4
    The computed view matrix, representing the camera's position and orientation in the world.
  • viewProjectionMatrix: mat4
    The combined matrix (Projection * View). This is the primary matrix used in vertex shaders to transform world coordinates to clip space.
  • bufferData: Float32Array
    A pre-allocated 20-float array (80 bytes). It contains the viewProjectionMatrix (indices 0-15) and the camera's eye position (indices 16-18), perfectly aligned for direct WebGPU Uniform Buffer upload.

Constructor

new Camera(fovDegrees, aspect, near, far)

Initializes the camera and computes the static perspective projection matrix.

  • fovDegrees (number): The Field of View in degrees (e.g., 45 or 60).
  • aspect (number): The aspect ratio of the canvas (width / height).
  • near (number): The near clipping plane distance.
  • far (number): The far clipping plane distance.

Methods

updateView(eye, target, up?)

Updates the camera's position and look target. This method recalculates the view matrix, updates the combined view-projection matrix, and writes the updated data directly into the bufferData array for GPU streaming.

  • eye (vec3): The 3D position of the camera in world space.
  • target (vec3): The 3D point the camera is looking at.
  • up (vec3): The upward direction vector. Defaults to [0, 1, 0] (Y-up).
  • Returns: void

Implementation Note: After calling updateView, you typically pass this camera instance to engine.updateCamera(camera) to write the bufferData to the WebGPU Uniform Buffer.
