The PBRShaderChunks module and buildPBRShader function provide a dynamic WGSL shader generation system for physically-based rendering in NullGraph. Together they assemble vertex and fragment shaders by composing reusable WGSL code chunks based on a material's configuration, supporting both static and skinned meshes.

PBRShaderChunks (Module Constant)

Contains pre-written WGSL code blocks used as building blocks for PBR shader generation. Each chunk encapsulates a specific set of bindings, structs, or mathematical functions.

PBRChunks.CommonBindings

The core bindings and structs required by every PBR shader variant.

Contents

  • Constants: PI (π as f32)
  • Camera struct (uniform, group 0, binding 0):
    • viewProj: mat4x4<f32> — The combined view-projection matrix
    • eyePos: vec3<f32> — World-space camera position
    • simTime: f32 — Simulation time in seconds
  • ECS storage buffer (storage, read, group 0, binding 1):
    • ecs: array<f32> — Engine component storage containing per-instance transform data (packed as 14 floats per instance)
  • Material bindings (group 1):
    • samp: sampler (binding 0) — Texture sampler
    • texAlbedo: texture_2d<f32> (binding 1) — Albedo/base color map
    • texNormal: texture_2d<f32> (binding 2) — Normal map
    • texMRAO: texture_2d<f32> (binding 3) — Packed metallic/roughness/AO map
  • MaterialParams struct (uniform, group 1, binding 4):
    • baseColor: vec4<f32> — RGBA tint color
    • metallic: f32 — Metallic multiplier
    • roughness: f32 — Roughness multiplier
    • mapFormat: f32 — Packed map channel selector (0.0 for ARM, 1.0 for MRAO)
    • padding: f32 — Alignment padding (unused)
  • VertexOut struct — Output from vertex shader to fragment shader:
    • clipPos: vec4<f32> — Clip-space position (@builtin(position))
    • worldPos: vec3<f32> — World-space position (@location(0))
    • worldNormal: vec3<f32> — World-space normal (@location(1))
    • uv: vec2<f32> — Texture coordinates (@location(2))

PBRChunks.SkinningBindings

Optional bindings included only when a mesh is skinned.

Contents

  • Skeleton struct (uniform, group 2, binding 0):
    • boneMatrices: array<mat4x4<f32>, 70> — Array of bone transformation matrices (supports up to 70 bones)

PBRChunks.PBRMath

Mathematical utility functions used in PBR lighting calculations.

Functions

  • DistributionGGX(N, H, roughness)
    Computes the GGX/Trowbridge-Reitz normal distribution function.
    Parameters: N: vec3<f32>, H: vec3<f32>, roughness: f32
    Returns: f32
  • rotateVector(v, q)
    Rotates a 3D vector by a quaternion.
    Parameters: v: vec3<f32>, q: vec4<f32> (quaternion as vec4)
    Returns: vec3<f32>
  • GeometrySchlickGGX(NdotV, roughness)
    Computes the Schlick-GGX geometry occlusion term for a single direction.
    Parameters: NdotV: f32, roughness: f32
    Returns: f32
  • GeometrySmith(N, V, L, roughness)
    Computes the combined Smith geometry shadowing/masking function.
    Parameters: N: vec3<f32>, V: vec3<f32>, L: vec3<f32>, roughness: f32
    Returns: f32
  • fresnelSchlick(cosTheta, F0)
    Computes the Schlick approximation for the Fresnel reflectance term.
    Parameters: cosTheta: f32, F0: vec3<f32> (surface reflectance at normal incidence)
    Returns: vec3<f32>
  • getNormalFromMap(uv, worldPos, worldNormal)
    Decodes a tangent-space normal from the normal map and transforms it to world space using screen-space derivatives.
    Parameters: uv: vec2<f32>, worldPos: vec3<f32>, worldNormal: vec3<f32>
    Returns: vec3<f32> — The perturbed world-space normal vector

buildPBRShader (Function)

Assembles a complete WGSL PBR shader string from the provided configuration and the PBRChunks module.

buildPBRShader(config)

Generates a PBR vertex and fragment shader pair.

  • config (ShaderConfig):
    Configuration object specifying which shader features to enable.
  • Returns: string
    A complete WGSL shader source string containing all bindings, structs, math functions, and the entry points vs_main and fs_main.

Configuration Interface

ShaderConfig (Interface)

Defines the features that can be toggled when building a PBR shader.

Properties

  • useSkinning: boolean
    Whether to include skeletal animation (bone transforms) in the vertex shader.
    When true: includes SkinningBindings, expects joint/weight vertex attributes, and applies skinned transforms.
    When false: uses static mesh transforms directly.

Vertex Shader Behavior

Vertex Attributes

  • @location(0) — Local-space position (vec3<f32>)
  • @location(1) — Normal vector (vec3<f32>)
  • @location(2) — UV coordinates (vec2<f32>)
  • @location(3) — Joint indices (vec4<f32>) — Only when useSkinning is true
  • @location(4) — Joint weights (vec4<f32>) — Only when useSkinning is true
  • @builtin(instance_index) — GPU instance index for ECS transform lookup

Transform Pipeline

  1. Fetch ECS transform (position, rotation quaternion, scale) from the ecs storage buffer using the instance index
  2. If skinning is enabled: compute the weighted skin matrix from four bone matrices and apply it to the local position and normal
  3. Apply scale, rotation (via quaternion), and translation to obtain world-space position
  4. Rotate the normal to world space
  5. Multiply by the camera view-projection matrix for clip-space output

Fragment Shader Behavior

PBR Lighting Model

  • Reads albedo from texAlbedo and multiplies by material.baseColor.rgb
  • Samples the packed ORM map (texMRAO) and interprets channels based on material.mapFormat:
    • ARM (mapFormat < 0.5): R=AO, G=Roughness, B=Metallic
    • MRAO (mapFormat ≥ 0.5): R=Metallic, G=Roughness, B=AO
  • Computes the perturbed world-space normal using getNormalFromMap
  • Calculates a single directional light contribution using the Cook-Torrance microfacet BRDF:
    • GGX normal distribution (DistributionGGX)
    • Smith geometry term (GeometrySmith)
    • Schlick Fresnel approximation (fresnelSchlick)
  • Adds constant ambient lighting modulated by albedo and AO
  • Applies Reinhard tonemapping and gamma correction (1/2.2)
  • Outputs the final color with the material's base alpha

Hardcoded Light

The current implementation uses a single hardcoded directional light:

  • Direction: normalize(vec3<f32>(1.0, 1.0, 0.5))
  • Color: vec3<f32>(3.0, 3.0, 3.0)
  • Ambient: vec3<f32>(0.3) * albedo * ao

Shader Assembly Order

The generated shader string is assembled in the following fixed order:

  1. PBRChunks.CommonBindings — Always included
  2. PBRChunks.SkinningBindings — Included only if config.useSkinning is true
  3. PBRChunks.PBRMath — Always included
  4. Vertex shader (vs_main)
  5. Fragment shader (fs_main)

Typical Workflow

import { buildPBRShader } from './ShaderBuilder';

// Build a shader for static meshes
const staticShader = buildPBRShader({ useSkinning: false });

// Build a shader for skinned meshes
const skinnedShader = buildPBRShader({ useSkinning: true });

// The resulting strings are ready to be used with device.createShaderModule()
const shaderModule = device.createShaderModule({ code: staticShader });

Notes

  • The ShaderConfig interface is designed with comments for future extensions (e.g., maxLights, useNormalMap, useAlphaClipping) but currently only useSkinning is functional.
  • Skinning supports up to 70 bone matrices as defined in the Skeleton struct.
  • Each ECS instance consumes 14 floats in the storage buffer: 2 reserved (base + 0u, base + 11u through base + 13u), 3 for position, 4 for rotation quaternion, and 3 for scale.
  • The normal map is mandatory for the current implementation; the fragment shader always calls getNormalFromMap, which samples texNormal.
