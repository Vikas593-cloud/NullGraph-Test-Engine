The WebGPUContext class encapsulates the native WebGPU initialization pipeline. It handles the adapter request, feature negotiation, canvas swapchain configuration, and base depth buffer management.

Public Properties

These properties are populated and available after init() has successfully resolved.

  • device: GPUDevice
    The initialized native WebGPU device used for creating buffers, textures, and pipelines.
  • context: GPUCanvasContext
    The WebGPU context attached to the HTML canvas.
  • format: GPUTextureFormat
    The preferred texture format of the canvas (determined by the user's OS/browser, usually 'bgra8unorm' or 'rgba8unorm').
  • depthTexture: GPUTexture
    The main depth buffer ('depth24plus') automatically sized to match the canvas dimensions.
  • cameraUniformBuffer: GPUBuffer
    A pre-allocated Uniform Buffer (80 bytes) dedicated to holding global camera state (View/Projection matrices).

Initialization & Lifecycle

init(canvas, desiredFeatures?)

Bootstraps the WebGPU environment. It performs fallback-safe feature negotiation, meaning it will only request features that the physical hardware actually supports, preventing initialization crashes.

  • canvas (HTMLCanvasElement): The target canvas to render to.
  • desiredFeatures (GPUFeatureName[]): An optional array of WebGPU features you want to enable (e.g., ['indirect-first-instance']). Unsuported features are safely ignored with a console warning. Defaults to [].
  • Returns: Promise<void>. Throws an error if WebGPU is not supported or no appropriate adapter is found.

Note: The canvas context is automatically configured with alphaMode: 'premultiplied' to ensure correct blending with DOM UI overlays.

resize(width, height)

Handles resizing events from the browser. Automatically safely destroys the old depth texture and allocates a new one matching the requested dimensions.

  • width (number): The new width in pixels.
  • height (number): The new height in pixels.
  • Returns: void

Note: This method includes safety checks to prevent crashes if resize events fire before the device is fully initialized, and enforces a minimum dimension of 1x1 to satisfy WebGPU texture constraints.
