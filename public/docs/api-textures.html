The TextureManager class handles texture loading, GPU texture allocation, sampler reuse, caching, and fallback texture generation for WebGPU rendering workflows.

Constructor

new TextureManager(device)

Creates a new texture manager bound to a specific WebGPU device.

  • device (GPUDevice): The active WebGPU device used for texture and sampler allocation.

Public Properties

  • defaultSampler: GPUSampler
    A reusable default sampler configured with:
    • magFilter: 'linear'
    • minFilter: 'linear'
    • addressModeU: 'repeat'
    • addressModeV: 'repeat'
    Intended for standard tiled 3D texture usage.

TextureLoadOptions (Interface)

Optional configuration used when loading textures through TextureManager.load().

Properties

  • sRGB?: boolean
    Controls whether the texture should be treated as an sRGB color texture.
    • true → Intended for Albedo/BaseColor textures.
    • false → Intended for data textures such as Normal, Metallic, Roughness, AO, etc.
    When enabled, the GPU automatically converts sampled values from sRGB to linear color space.
    • ```
  • samplerDescriptor?: GPUSamplerDescriptor
    Optional sampler configuration for custom filtering or addressing modes. Defaults to linear filtering with repeat addressing.
    • ```

Texture Loading

load(url, options?)

Fetches an image from a URL, decodes it into an ImageBitmap, uploads it to GPU memory, caches it, and returns a GPUTextureView.

  • url (string): Path or URL to the texture image.
    • ```
  • options (TextureLoadOptions): Optional loading configuration.
  • Returns: Promise<GPUTextureView>
    • ```

Behavior

  • Automatically caches textures to avoid duplicate VRAM uploads.
  • Uses rgba8unorm-srgb format when sRGB is enabled.
  • Uses rgba8unorm format for non-color/data textures.
  • Attempts strict color-space decoding first via createImageBitmap().
  • Falls back to standard decoding if browser-specific image decoding fails.
  • Uploads image data using queue.copyExternalImageToTexture().
  • Returns fallback textures automatically if loading or decoding fails.

Fallback Behavior

If texture loading fails, the manager returns a safe fallback texture so rendering can continue without shader errors.

  • Color textures typically fallback to a solid white texture.
  • Normal/data textures may fallback to neutral placeholder textures.

Sampler Management

getSampler(descriptor)

Creates or retrieves a cached sampler matching the provided descriptor.

  • descriptor (GPUSamplerDescriptor): The sampler configuration.
    • ```
  • Returns: GPUSampler
    • ```

Behavior

  • Samplers are cached internally using a serialized descriptor key.
  • Repeated requests with identical descriptors reuse the same GPU sampler object.

Texture Cache Management

clearCache()

Destroys all cached GPU textures and clears internal sampler caches.

  • Returns: void

Behavior

  • Calls GPUTexture.destroy() on all cached textures.
  • Clears both texture and sampler caches.
  • Typically used when unloading scenes or shutting down the renderer.

Solid Texture Utilities

getSolidTexture(r, g, b, a?)

Generates and caches a 1x1 solid-color GPU texture.

  • r (number): Red channel (0-255).
  • g (number): Green channel (0-255).
  • b (number): Blue channel (0-255).
  • a (number): Alpha channel (0-255). Defaults to 255.
    • ```
  • Returns: GPUTextureView
    • ```

Behavior

  • Creates a 1x1 rgba8unorm texture.
  • Uploads pixel data using queue.writeTexture().
  • Textures are cached by RGBA value to avoid duplicate allocations.

Fallback Texture Accessors

fallbackWhite

Returns a reusable solid white texture view.

  • Returns: GPUTextureView

fallbackNormal

Returns a reusable neutral normal-map texture view using RGB value (128, 128, 255).

  • Returns: GPUTextureView

Internal Caching Strategy

  • textureCache: Map<string, GPUTexture>
    Prevents duplicate texture uploads by caching textures per URL and color-space combination.
    • ```
  • samplerCache: Map<string, GPUSampler>
    Reuses sampler objects for identical sampler descriptors.
  • solidTextures: Map<string, GPUTextureView>
    Stores generated 1x1 solid-color textures keyed by RGBA value.
    • ```
