The NullGraph class is the primary entry point for the engine. It manages the WebGPU device context, rendering pipeline, passes, and batches.

Public Properties

  • device: GPUDevice
    The native WebGPU device instance. Available only after init() has successfully resolved.
  • bufferManager: BufferManager
    Utility for managing GPU buffers (Vertex, Index, Uniform, Storage).
  • textureManager: TextureManager
    Utility for managing GPU textures and samplers.

Initialization & Lifecycle

init(canvas, options?)

Initializes the WebGPU context, requests a device, and sets up internal managers.

  • canvas (HTMLCanvasElement): The target canvas for rendering.
  • options ({ desiredFeatures?: GPUFeatureName[] }): Optional configuration to request specific WebGPU features (e.g., 'indirect-first-instance').
  • Returns: Promise<EngineInitResult> containing a success flag, enabled features, or an error message.

resize(width, height)

Resizes the underlying WebGPU context and swap chain to match the new dimensions.

  • width (number): New width in pixels.
  • height (number): New height in pixels.
  • Returns: void

Pass Management

createPass(config)

Creates a new Render Pass node. Passes can be chained for off-screen rendering or post-processing.

  • config (RenderPassConfig): Configuration for color/depth attachments and clear values.
  • Returns: RenderPassNode

clearPasses()

Clears all currently tracked render passes from the engine.

  • Returns: void

Batch Management

createBatch(pass, config)

Creates a render batch within a specific pass. A batch represents a single draw call (or indirect draw) with a shared shader pipeline and vertex layout.

  • pass (RenderPassNode): The pass this batch belongs to.
  • config (PipelineConfig): Shader code, instance limits, stride, and pipeline layout.
  • Returns: RenderBatch

setBatchGeometry(batch, vertexBuffer, indexBuffer, indexCount, format?)

Binds the static geometry (VBO/IBO) to a specific batch.

  • batch (RenderBatch): The target batch.
  • vertexBuffer (GPUBuffer): The buffer containing vertex data.
  • indexBuffer (GPUBuffer): The buffer containing index data.
  • indexCount (number): Total number of indices to draw.
  • format (GPUIndexFormat): Format of the indices. Defaults to 'uint16'.
  • Returns: void

updateBatchData(batch, rawData, instanceCount)

Streams contiguous flat array data directly to the GPU for this batch's instances.

  • batch (RenderBatch): The target batch.
  • rawData (Float32Array): The flat DOD array containing instance state (transforms, colors, etc.).
  • instanceCount (number): The number of active instances to render.
  • Returns: void

clearBatch(pass, batch)

Cleans up GPU resources for a specific batch and removes it from the pass.

  • pass (RenderPassNode): The pass containing the batch.
  • batch (RenderBatch): The batch to remove.
  • Returns: void

clearBatches()

Clears all tracked render batches globally from the engine instance.

  • Returns: void

Materials & Bind Groups

attachTextureMaterial(batch, textureView, sampler, extraEntries?, groupIndex?)

Binds a texture and sampler to a batch. Useful for applying diffuse maps or chaining post-processing buffers.

  • batch (RenderBatch): The target batch.
  • textureView (GPUTextureView | GPUTextureView[]): The texture view(s) to bind.
  • sampler (GPUSampler): The sampler for texture filtering.
  • extraEntries (GPUBindGroupEntry[]): Optional additional buffer bindings to append to this group. Defaults to [].
  • groupIndex (number): The bind group index in the shader. Defaults to 1.
  • Returns: GPUBindGroup

attachCustomBindGroup(batch, entries, groupIndex?, target?)

Attaches a completely custom bind group to a batch for advanced rendering or compute parameters.

  • batch (RenderBatch): The target batch.
  • entries (GPUBindGroupEntry[]): The layout entries for the bind group.
  • groupIndex (number): The bind group index in the shader. Defaults to 1.
  • target ('render' | 'compute' | 'both'): Which pipeline this bind group applies to. Defaults to 'render'.
  • Returns: void

Rendering

updateCamera(camera)

Updates the global camera uniform buffer. This writes 80 bytes (20 floats representing the View/Projection matrices and Camera Position) to the GPU.

  • camera (Camera): The camera instance containing the updated buffer data.
  • Returns: void

render()

Submits the current frame to the GPU. This traverses all registered passes and executes their associated batches.

  • Returns: void

This document details the core data structures and interfaces that drive NullGraph's Render Batches and Pipeline Configurations.

PipelineConfig (Interface)

The configuration object required when creating a new Render Batch via engine.createBatch(pass, config). It defines the shader pipeline, memory layout, and optional compute-driven indirect rendering settings.

Required Properties

  • shaderCode: string
    The WGSL source code for the vertex and fragment shaders.
  • strideFloats: number
    The number of 32-bit floats per instance in your Data-Oriented array (e.g., 16 for a 4x4 matrix).
  • maxInstances: number
    The maximum number of instances this batch will pre-allocate memory for.

Optional Pipeline Properties

  • vertexLayouts?: GPUVertexBufferLayout[]
    The layout descriptors for the static vertex buffers. Required if rendering geometry.
  • topology?: GPUPrimitiveTopology
    The primitive topology (e.g., 'triangle-list', 'line-list').
  • targetFormats?: GPUTextureFormat[]
    Formats of the color attachments this pipeline renders to.
  • targetFormat?: GPUTextureFormat
    Convenience property for a single color attachment format.
  • material?: Material
    An optional material instance to bind to this pipeline automatically.

Depth & Blend State

  • depthWriteEnabled?: boolean
    Whether to write to the depth buffer.
  • depthCompare?: GPUCompareFunction
    The depth testing function (e.g., 'less', 'less-equal').
  • blend?: GPUBlendState
    Alpha blending configuration.

GPU-Driven & Compute Properties

  • isIndirect?: boolean
    If true, the batch will use drawIndexedIndirect instead of standard instanced drawing.
  • computeShaderCode?: string
    WGSL code for a compute shader to process instances and write indirect draw commands.
  • sharedSourceBuffer?: GPUBuffer
    An optional buffer shared between passes to avoid uploading data multiple times.
  • extraBindGroup?: GPUBindGroup
    An optional extra bind group to attach to the pipeline.

RenderBatch (Class)

Represents a single rendering workload (Draw Call / Indirect Draw). Instances of this class are created and managed internally by the BatchManager and returned to you. Do not instantiate directly.

Core State

  • pipeline: GPURenderPipeline
    The compiled WebGPU render pipeline.
  • storageBuffer: GPUBuffer
    The pre-allocated Storage Buffer mapped to your main thread's Float32Array.
  • bindGroup: GPUBindGroup
    The primary bind group containing the storage buffer.
  • stride: number
    The float stride for the instance data.

Geometry State

  • vertexBuffer: GPUBuffer | null
    The bound static vertex buffer.
  • indexBuffer: GPUBuffer | null
    The bound static index buffer.
  • indexCount: number
    Total number of indices to draw per instance.
  • indexFormat: GPUIndexFormat
    Defaults to 'uint16'.

Instance Tracking

  • currentInstanceCount: number
    The number of active instances currently queued for rendering.
  • maxInstanceCount?: number
    The capacity limit of the allocated storage buffer.

Indirect & Compute State

  • isIndirect: boolean
    Flags if the batch is utilizing compute-driven indirect drawing.
  • indirectBuffer?: GPUBuffer
    The buffer containing the IndirectDrawArgs.
  • sourceStorageBuffer?: GPUBuffer
    The raw un-culled data buffer read by the compute shader.
  • computePipeline?: GPUComputePipeline
    The compute pipeline responsible for culling/processing.
  • computeBindGroup?: GPUBindGroup
    The bind group used by the compute shader.
  • customBindGroups: Record<number, GPUBindGroup>
    Custom bind groups mapped by their group index for the render pass.
  • computeCustomBindGroups: Record<number, GPUBindGroup>
    Custom bind groups mapped by their group index for the compute pass.

Material (Interface)

A pluggable interface for managing textures, samplers, or complex uniform bindings that can be attached to batches.

  • applyToBatch(batch: RenderBatch, groupIndex?: number): GPUBindGroup
    Binds the material's resources to the specified batch and returns the generated WebGPU bind group.
  • destroy(): void
    Cleans up the underlying WebGPU resources (textures, samplers) associated with this material.

EngineInitResult (Interface)

The standard response returned when calling await engine.init().

  • success: boolean
    True if the WebGPU context was successfully requested and configured.
  • enabledFeatures: ReadonlySet<string>
    A set of WebGPU feature strings successfully enabled on the device.
  • error?: string
    Contains the error message if success is false.
