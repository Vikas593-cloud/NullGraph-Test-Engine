The StandardPBRMaterial class implements a physically-based rendering material for NullGraph, providing albedo, normal, and packed (metallic/roughness/AO) texture maps alongside uniform parameters for metallic, roughness, and base color control.

StandardPBRMaterial (Class)

Represents a PBR material with texture maps and material parameters. It manages GPU uniform buffers, bind group creation, and provides a streamlined interface for applying the material to render batches.

The class handles safe fallback textures, uniform buffer creation, and binding to the engine's material pipeline automatically.

Constructor

new StandardPBRMaterial(engine, options)

Creates a new PBR material instance with the specified textures and parameters.

  • engine (NullGraph):
    The engine instance providing GPU device access and texture management.
  • options (PBRMaterialOptions):
    Configuration object for the material's textures and properties.

Configuration Interface

PBRMaterialOptions (Interface)

Defines the configuration options for creating a StandardPBRMaterial.

Properties

  • albedoMap?: GPUTextureView
    The base color/albedo texture map.
    Falls back to a white texture if not provided.
  • normalMap?: GPUTextureView
    The normal map for surface detail.
    Falls back to a default normal texture (flat surface) if not provided.
  • packedMap?: GPUTextureView
    Packed texture containing metallic, roughness, and ambient occlusion data.
    Falls back to a white texture if not provided.
  • packedMapFormat?: 'ARM' | 'MRAO'
    Specifies the channel packing format of the packed map.
    'ARM' — Ambient Occlusion in R, Roughness in G, Metallic in B.
    'MRAO' — Metallic in R, Roughness in G, Ambient Occlusion in B.
    Defaults to 'ARM' implicitly.
  • baseColor?: [number, number, number, number]
    RGBA tint color multiplied with the albedo map.
    Defaults to [1.0, 1.0, 1.0, 1.0] (white, fully opaque).
  • metallicMultiplier?: number
    Scalar multiplier applied to the metallic value sampled from the packed map.
    Defaults to 1.0.
  • roughnessMultiplier?: number
    Scalar multiplier applied to the roughness value sampled from the packed map.
    Defaults to 1.0.

Public Properties

  • albedoMap: GPUTextureView
    The currently assigned albedo/base color texture view.
  • normalMap: GPUTextureView
    The currently assigned normal map texture view.
  • packedMap: GPUTextureView
    The currently assigned packed (ORM/MRAO) texture view.

Material Binding

applyToBatch(batch, groupIndex?)

Attaches this material's textures and uniform parameters to a specific render batch, creating the necessary GPU bind group.

  • batch (RenderBatch):
    The render batch to apply the material to.
  • groupIndex (number):
    Optional bind group index (default: 1). Specifies which bind group slot this material occupies in the shader.
  • Returns: GPUBindGroup
    The generated GPU bind group containing the material's textures and uniform buffer.

Behavior

  • Binds the albedo, normal, and packed texture maps to the batch.
  • Creates a uniform buffer binding containing base color, metallic, roughness, packed map format flag, and padding.
  • Uses the engine's default sampler for all three texture maps.
  • Internally calls engine.attachTextureMaterial() to handle GPU bind group layout matching.
  • Caches the resulting bind group for potential reuse.

Uniform Parameter Updates

updateUniforms(baseColor, metallic, roughness)

Updates the material's uniform parameters during runtime and writes them to the GPU buffer.

  • baseColor ([number, number, number, number]):
    New RGBA base color values.
  • metallic (number):
    New metallic multiplier value.
  • roughness (number):
    New roughness multiplier value.
  • Returns: void

Behavior

  • Constructs a new uniform data array with the provided values.
  • Writes the updated data directly to the GPU uniform buffer via the device queue.
  • Note: The internal packed map format flag is reset to 0.0 (ARM) in this method; subsequent calls may overwrite it. Future updates should preserve or accept the format flag separately.

Resource Cleanup

destroy()

Releases the GPU uniform buffer associated with this material.

  • Returns: void

Behavior

  • Calls GPUBuffer.destroy() on the internal uniform buffer.
  • Texture views are not destroyed, as they are managed externally by the engine's texture manager or user code.

Internal Uniform Buffer Layout

The material's uniform buffer uses the following 32-byte packed layout (Float32Array):

Offset (bytes) Field Type Description
0 baseColor.r f32 Red channel of base color
4 baseColor.g f32 Green channel of base color
8 baseColor.b f32 Blue channel of base color
12 baseColor.a f32 Alpha channel of base color
16 metallicMultiplier f32 Metallic scalar multiplier
20 roughnessMultiplier f32 Roughness scalar multiplier
24 packedMapFormat f32 0.0 for ARM, 1.0 for MRAO
28 _padding f32 Padding for alignment (unused)

Typical Workflow

// Create a material with custom textures
const material = new StandardPBRMaterial(engine, {
    albedoMap: brickAlbedo,
    normalMap: brickNormal,
    packedMap: brickPacked,
    packedMapFormat: 'ARM',
    baseColor: [1.0, 0.9, 0.8, 1.0],
    metallicMultiplier: 0.5,
    roughnessMultiplier: 1.2
});

// Apply to a render batch
const bindGroup = material.applyToBatch(myBatch, 1);

// Later, update material parameters at runtime
material.updateUniforms([1.5, 0.7, 0.3, 1.0], 0.8, 0.6);

// Clean up when no longer needed
material.destroy();

The material's textures remain managed externally; only the internal uniform buffer is destroyed when destroy() is called.
