The GLBParser class provides a complete static parser for the custom GLB (GL Binary) format, loading 3D model data from URLs or raw ArrayBuffer instances. It handles scene graph traversal, skinned and static mesh extraction with dynamic vertex strides, transform baking, material texture URL resolution, skeletal skin data, and animation clip extraction — all with support for merging multi-mesh scenes into single GPU-ready geometry.

GLBParser (Class)

A fully static utility class for parsing GLB files into NullGraph-compatible geometry data, skin data, and animation data.

All methods are static; no instantiation is required or intended.

Core Loading Methods

GLBParser.load(url)

Fetches and parses a GLB file from a URL.

  • url (string):
    The URL path to the GLB file to fetch.
  • Returns: Promise<GLBData>
    A promise resolving to the parsed GLB data, containing meshes, optional skin data, optional animations, and optional image URLs.

Behavior

  • Uses fetch() to download the binary file.
  • Converts the response to an ArrayBuffer.
  • Delegates to GLBParser.parse() for processing.

GLBParser.parse(arrayBuffer)

Parses a raw GLB binary buffer into structured geometry, skin, and animation data.

  • arrayBuffer (ArrayBuffer):
    The raw binary data of a GLB file.
  • Returns: GLBData
    The parsed data structure containing meshes, skin, and animations.

Behavior

  1. Validates the GLB magic number (0x46546C67).
  2. Extracts and parses the JSON chunk as the glTF scene descriptor.
  3. Locates the binary chunk offset for buffer data access.
  4. Extracts image URLs (including embedded binary blobs) from the image array.
  5. Traverses the default scene's node hierarchy, processing all meshes.
  6. Extracts skin (skeleton) data if present.
  7. Extracts animation clips if present.

Scene Graph Processing

GLBParser.processNode(gltf, nodeIndex, parentMatrix, buffer, binOffset, geometries, imageUrls) (Private)

Recursively processes a scene graph node, applying hierarchical transforms and extracting geometry.

  • gltf (any): The parsed glTF JSON object.
  • nodeIndex (number): The index of the node to process.
  • parentMatrix (Float32Array): The accumulated world matrix from parent nodes.
  • buffer (ArrayBuffer): The raw binary buffer for geometry data.
  • binOffset (number): Byte offset to the start of the binary chunk.
  • geometries (RawGeometryData[]): Accumulator array for extracted geometries.
  • imageUrls (string[]): Array of resolved image URLs.

Behavior

  • Computes the node's local transform matrix from TRS properties or explicit matrix data.
  • Multiplies with the parent matrix to obtain a world matrix.
  • If the node references a mesh, extracts all primitives.
  • Static meshes: The world transform is baked directly into vertex positions and normals.
  • Skinned meshes: Vertex data is kept in local space (no transform baking), and skinning attributes are extracted.
  • Recursively processes all child nodes with the computed world matrix.

GLBParser.bakeTransform(geom, matrix) (Private)

Bakes a world transform matrix into the vertex positions and normals of a static mesh.

  • geom (RawGeometryData):
    The geometry whose vertices will be transformed in-place.
  • matrix (Float32Array):
    The 4×4 world transform matrix to apply.

Behavior

  • Uses a fixed stride of 8 floats (position: 3, normal: 3, UV: 2) since it is never called on skinned meshes.
  • Transforms each vertex position using MathUtils.transformPos.
  • Transforms each vertex normal using MathUtils.transformNorm.
  • Overwrites the vertex data in-place.

Primitive Extraction

GLBParser.extractPrimitive(gltf, buffer, binBufferOffset, primitive, isSkinned, imageUrls) (Private)

Extracts a single mesh primitive from the GLB data, returning RawGeometryData with a dynamic vertex layout.

  • gltf (any): The parsed glTF JSON.
  • buffer (ArrayBuffer): The raw binary buffer.
  • binBufferOffset (number): Byte offset to the binary chunk.
  • primitive (any): The glTF primitive object to extract.
  • isSkinned (boolean): Whether this primitive belongs to a skinned mesh.
  • imageUrls (string[]): Array of resolved image URLs for material texture lookup.
  • Returns: RawGeometryData
    The extracted geometry with dynamic vertex layout.

Dynamic Vertex Layout

The method uses a variable vertex stride depending on the skinning state:

Stride Attributes Shader Locations Used For
8 floats (32 bytes) Position (3), Normal (3), UV (2) @location(0), @location(1), @location(2) Static meshes
16 floats (64 bytes) Position (3), Normal (3), UV (2), Joints (4), Weights (4) @location(0), @location(1), @location(2), @location(3), @location(4) Skinned meshes

Attribute Reading

Internal readAttribute helper supports multiple component types:

  • 5126 (FLOAT) — Used for positions, normals, UVs, and weights.
  • 5123 (UNSIGNED_SHORT) — Used for joint indices (common in glTF).
  • 5121 (UNSIGNED_BYTE) — Used for joint indices (compact encoding).

Fallback Values

  • Missing normals default to (0, 1, 0).
  • Missing UVs default to (0, 0).
  • Missing joint indices default to 0.
  • Missing weights default to 1.0 (first weight channel).

Index Buffer Handling

Supports three index component types:

  • 5125 (UNSIGNED_INT) — Produces Uint32Array.
  • 5123 (UNSIGNED_SHORT) — Produces Uint16Array.
  • 5121 (UNSIGNED_BYTE) — Produces Uint16Array (values upcast).

Material Texture Extraction

Resolves texture URLs from the glTF material definition:

  • Albedo: From pbrMetallicRoughness.baseColorTexture.
  • Metallic-Roughness: From pbrMetallicRoughness.metallicRoughnessTexture.
  • Normal: From material.normalTexture.
  • Occlusion: From material.occlusionTexture.
  • Emissive: From material.emissiveTexture.

Each URL is resolved from the imageUrls array using the texture's source index.

Mesh Merging

GLBParser.loadMerged(url)

Loads a GLB file and merges all meshes into a single combined geometry object.

  • url (string):
    The URL path to the GLB file.
  • Returns: Promise<GLBData>
    A promise resolving to GLB data containing a single merged mesh in the meshes array, plus any skin and animation data.

Behavior

  • Loads the file using GLBParser.load().
  • If only one mesh exists, returns the data unchanged.
  • If multiple meshes exist:
    • Calculates the total vertex count and total index count.
    • Creates a merged vertex buffer using the stride of the first mesh (ensuring consistency for skinned vs. static).
    • Creates a merged Uint32Array index buffer with corrected index offsets.
    • Preserves the WebGPU vertex layout function from the first mesh.
  • Returns a new GLBData object with the single merged mesh.

Note

Merging is only safe when all meshes share the same skinning state and vertex layout. Mixing static and skinned meshes will produce incorrect results.

Skin Data Extraction

GLBParser.extractSkin(gltf, buffer, binBufferOffset)

Extracts skeletal skinning data from the glTF file.

  • gltf (any): The parsed glTF JSON.
  • buffer (ArrayBuffer): The raw binary buffer.
  • binBufferOffset (number): Byte offset to the binary chunk.
  • Returns: GLBSkin | null
    The extracted skin data, or null if no skin is present.

GLBSkin Data Structure

  • joints: number[] — Array of node indices that form the skeleton's joints.
  • inverseBindMatrices: Float32Array — Flattened array of 4×4 inverse bind matrices (one per joint).
  • nodes: any[] — Reference to the glTF nodes array for bone hierarchy lookup.

Animation Extraction

GLBParser.extractAnimations(gltf, buffer, binBufferOffset)

Extracts animation clips from the glTF file.

  • gltf (any): The parsed glTF JSON.
  • buffer (ArrayBuffer): The raw binary buffer.
  • binBufferOffset (number): Byte offset to the binary chunk.
  • Returns: GLBAnimation[]
    Array of animation clips (empty if none present).

GLBAnimation Data Structure

  • name: string — Animation name (defaults to 'Animation').
  • channels: Array — Channel descriptors:
    • targetNode: number — Index of the target node.
    • path: string — Animated property path ('translation', 'rotation', or 'scale').
    • samplerIndex: number — Index into the samplers array.
  • samplers: Array — Sampler descriptors:
    • input: Float32Array — Keyframe time values.
    • output: Float32Array — Keyframe data (vec3 for translation/scale, vec4 for rotation quaternions).
    • interpolation: string — Interpolation type ('LINEAR', 'STEP', or 'CUBICSPLINE').
  • maxTime: number — The maximum keyframe time in the animation (duration).

Image URL Management

GLBParser.extractImageURLs(gltf, buffer, binBufferOffset)

Extracts and resolves image URLs from the glTF image array.

  • gltf (any): The parsed glTF JSON.
  • buffer (ArrayBuffer): The raw binary buffer.
  • binBufferOffset (number): Byte offset to the binary chunk.
  • Returns: string[]
    Array of resolved image URLs, aligned with the glTF image index.

Supported Image Sources

  • Data URIs: Returns the embedded Base64 string directly.
  • Buffer Views: Extracts binary image data, creates a Blob with the declared MIME type (defaults to 'image/png'), and returns an ObjectURL via URL.createObjectURL.
  • Missing/Unsupported: Returns an empty string.

GLBParser.disposeImages(gltf)

Revokes all blob URLs created during image extraction to prevent memory leaks.

  • gltf (GLBData):
    The parsed GLB data object containing an imageUrls array.
  • Returns: void

Behavior

  • Iterates over all URLs in the imageUrls array.
  • Calls URL.revokeObjectURL on each to release memory.
  • Should be called when the GLB data and its associated textures are no longer needed.

Return Data Structure

GLBData (Interface)

The top-level data structure returned by all load and parse methods.

  • meshes: RawGeometryData[] — Array of extracted geometry objects.
  • skin: GLBSkin | null — Skeletal skinning data if present, otherwise null.
  • animations: GLBAnimation[] — Array of animation clips.
  • imageUrls?: string[] — Optional. Array of resolved image URLs, present when loaded via load() or parse(). Not present in merged output.

RawGeometryData (Interface)

  • vertices: Float32Array — Interleaved vertex data.
  • indices: Uint16Array | Uint32Array — Index buffer data.
  • indexCount: number — Total number of indices.
  • vertexCount: number — Total number of vertices.
  • isSkinned: boolean — Whether the geometry uses skinning.
  • albedoUrl?: string — Resolved URL for the albedo/base color texture.
  • normalUrl?: string — Resolved URL for the normal map texture.
  • metallicRoughnessUrl?: string — Resolved URL for the metallic-roughness texture.
  • occlusionUrl?: string — Resolved URL for the occlusion texture.
  • emissiveUrl?: string — Resolved URL for the emissive texture.
  • getWebGPULayout: () => GPUVertexBufferLayout[] — Function returning the WebGPU vertex buffer layout descriptor(s) for this geometry.

Typical Workflow

import { GLBParser } from './GLBParser';

// Load a GLB file (single or multi-mesh)
const glbData = await GLBParser.load('models/character.glb');

// Access extracted data
for (const mesh of glbData.meshes) {
    console.log(`Mesh: ${mesh.vertexCount} vertices, ${mesh.indexCount} indices`);
    console.log(`Skinned: ${mesh.isSkinned}`);
    console.log(`Albedo: ${mesh.albedoUrl}`);
}

// Get WebGPU vertex layout for buffer creation
const layout = glbData.meshes[0].getWebGPULayout();

// Check for animations
if (glbData.animations.length > 0) {
    console.log(`Animation: ${glbData.animations[0].name}`);
    console.log(`Duration: ${glbData.animations[0].maxTime}s`);
}

// Clean up blob URLs when finished
GLBParser.disposeImages(glbData);

// Alternatively, load and merge all meshes into one
const mergedData = await GLBParser.loadMerged('models/level.glb');
const singleMesh = mergedData.meshes[0]; // Single combined geometry
