The Animator class provides a runtime skeletal animation playback system for NullGraph. It evaluates glTF-compatible animation clips on a full node hierarchy, computes global transforms via recursive tree traversal with frame caching, and outputs flattened skinning matrices ready for direct upload to WebGPU shaders.

Animator (Class)

Manages skeletal animation playback for a single skinned mesh. It supports looping animation clips, interpolates translation, rotation (via spherical linear interpolation), and scale channels, and computes the final array of skinning matrices for GPU consumption.

The animator operates on the entire scene node tree — not just joints — ensuring correct global transform propagation when intermediate nodes (such as armature roots) carry animation data.

Constructor

new Animator(skin)

Creates a new animator for the given skin data, allocating all required memory and resetting to the bind pose.

  • skin (GLBSkin):
    The skin data extracted from a GLB file, containing the joint array, inverse bind matrices, and the full node hierarchy.

Internal Allocation

Upon construction, the animator pre-allocates typed arrays sized for the entire node tree:

Array Size Description
localTranslations nodeCount × 3 Per-node local translation vectors
localRotations nodeCount × 4 Per-node local rotation quaternions (xyzw)
localScales nodeCount × 3 Per-node local scale vectors
localMatrices nodeCount × 16 Per-node local 4×4 transformation matrices
globalMatrices nodeCount × 16 Per-node world-space 4×4 transformation matrices (cached per frame)
globalComputed nodeCount Per-frame dirty flags (0 = not computed, 1 = computed)
nodeParents nodeCount Precomputed parent index for each node (-1 for root nodes)
skinningMatrices jointCount × 16 Final output: flattened 4×4 skinning matrices for GPU upload

Public Methods

play(animation)

Begins playback of the specified animation clip from time zero.

  • animation (GLBAnimation):
    The animation clip to play.
  • Returns: void

Behavior

  • Sets the provided animation as the current clip.
  • Resets the playback time to 0.
  • Calls resetToBindPose() to restore all nodes to their default transforms before evaluation begins. This prevents pose contamination from previously played animations.

update(deltaTime)

Advances the animation time, evaluates the current clip, and recomputes the skinning matrix output.

  • deltaTime (number):
    Time elapsed since the last frame, in seconds.
  • Returns: void

Behavior

  1. Increments the internal time accumulator by deltaTime.
  2. Loops the animation if the time exceeds maxTime (using modulo wrap).
  3. Calls evaluateAnimation() to sample and interpolate all channels.
  4. Calls computeMatrices() to rebuild the local, global, and skinning matrices.

Idle Behavior

If no animation is currently playing (currentAnimation === null), the method returns immediately without modifying any state.

getSkinningMatrices()

Returns the current array of flattened 4×4 skinning matrices suitable for direct upload to a WebGPU uniform or storage buffer.

  • Returns: Float32Array
    A Float32Array of length jointCount × 16, where each consecutive group of 16 floats represents a single 4×4 skinning matrix in column-major order.

Usage

The returned buffer is a live view into the animator's internal state. It should be written to the GPU each frame that the animation advances:

// Each frame:
animator.update(deltaTime);
const matrices = animator.getSkinningMatrices();
engine.device.queue.writeBuffer(skeletonUniformBuffer, 0, matrices);

Internal Methods

resetToBindPose() (Private)

Restores all nodes to their default transforms as defined in the glTF node data.

  • Returns: void

Behavior

  • Iterates over every node in the skin's node array.
  • Reads the default translation, rotation, and scale from each node definition.
  • Defaults missing translation to [0, 0, 0], rotation to [0, 0, 0, 1] (identity quaternion), and scale to [1, 1, 1].
  • Writes these defaults into the localTranslations, localRotations, and localScales arrays.

evaluateAnimation() (Private)

Samples the current animation at the current time and interpolates all active channels into the local transform arrays.

  • Returns: void

Keyframe Lookup

For each channel, the method finds the two surrounding keyframes by scanning the sampler's time array until times[frameIdx + 1] >= currentTime.

Interpolation

The interpolation factor is calculated as:

factor = (currentTime - t0) / (t1 - t0)

Channel interpolation by path:

Path Method Component Count
'translation' Linear interpolation (MathUtils.lerp) 3 (vec3)
'rotation' Spherical linear interpolation (MathUtils.slerp) 4 (quaternion)
'scale' Linear interpolation (MathUtils.lerp) 3 (vec3)

All interpolated values are written directly into the corresponding localTranslations, localRotations, or localScales arrays at the node's offset.

computeMatrices() (Private)

Rebuilds all local, global, and skinning matrices for the current frame.

  • Returns: void

Step 1: Local Matrix Construction

For every node, a 4×4 local transformation matrix is built from the current translation, rotation quaternion, and scale using MathUtils.fromTRS.

Step 2: Global Matrix Computation (Recursive with Caching)

A recursive helper function getGlobal(nodeIndex) computes the world-space matrix for each node:

  • If the node's global matrix was already computed this frame (checked via globalComputed flag), the cached value is returned immediately.
  • If the node is a root (no parent, nodeParents[i] === -1), its global matrix equals its local matrix.
  • Otherwise, the global matrix is computed as:
    global = parentGlobal × local
  • The result is stored in globalMatrices and marked as computed in globalComputed.

Step 3: Skinning Matrix Assembly

For each joint in the skin:

  1. The joint's global matrix is fetched via getGlobal(jointNodeIndex).
  2. The corresponding inverse bind matrix is read from the skin data.
  3. The final skinning matrix is computed as:
    skinMatrix = globalMatrix × inverseBindMatrix
  4. The result is stored in the skinningMatrices output array.

Performance Optimization

  • The globalComputed dirty flag array prevents redundant global matrix calculations for nodes that are ancestors of multiple joints.
  • The parent lookup uses a precomputed nodeParents array (Int16Array) for O(1) parent index access.
  • Recursion depth is bounded by the maximum node hierarchy depth, and caching ensures each node's global matrix is computed at most once per frame.

Typical Workflow

import { GLBParser } from './GLBParser';
import { Animator } from './Animator';

// Load a skinned model
const glbData = await GLBParser.load('character.glb');
const skin = glbData.skin;

// Create an animator for the skin
const animator = new Animator(skin);

// Start playing an animation clip
animator.play(glbData.animations[0]);

// In the render loop:
function frame(deltaTime: number) {
    animator.update(deltaTime);

    const skinningMatrices = animator.getSkinningMatrices();
    device.queue.writeBuffer(skeletonBuffer, 0, skinningMatrices);

    // Proceed with rendering...
}

// Switch animations at any time:
animator.play(glbData.animations[1]); // Resets to bind pose and plays new clip
