The MathUtils module provides a collection of lightweight, allocation-conscious mathematical utility functions for 3D graphics. It includes matrix operations (identity, multiplication, TRS construction), vector transformation (position and normal), and interpolation functions (linear and spherical) — all operating on plain Float32Array and number[] types without external dependencies.

MathUtils (Module Constant)

A static utility object containing pure functions for matrix math, vector transforms, and animation interpolation used throughout the NullGraph pipeline (GLB parsing, animation evaluation, and transform baking).

All methods are pure functions with no internal state. No instantiation is required.

Matrix Construction

MathUtils.identity()

Creates and returns a new 4×4 identity matrix.

  • Returns: Float32Array
    A 16-element Float32Array representing a column-major 4×4 identity matrix. Diagonal elements are 1.0; all other elements are 0.0.

Behavior

Allocates and returns a new buffer each call. The output is suitable for direct use as a default transform, bind pose matrix, or multiplicative identity.

MathUtils.fromTRS(t, r, s)

Constructs a 4×4 affine transformation matrix from translation, rotation (quaternion), and scale components.

  • t (number[] | [number, number, number]):
    Translation vector [x, y, z].
  • r (number[] | [number, number, number, number]):
    Rotation quaternion [x, y, z, w].
  • s (number[] | [number, number, number]):
    Scale vector [x, y, z].
  • Returns: Float32Array
    A 16-element Float32Array representing the combined TRS matrix in column-major order.

Matrix Layout

The resulting matrix is constructed as:

M = T × R × S

Where the rotation submatrix is derived from the quaternion using the standard conversion:

Column Row 0 Row 1 Row 2 Row 3
0 1 - 2(yy + zz) 2(xy + wz) 2(xz - wy) 0
1 2(xy - wz) 1 - 2(xx + zz) 2(yz + wx) 0
2 2(xz + wy) 2(yz - wx) 1 - 2(xx + yy) 0
3 t[0] t[1] t[2] 1

Scale is multiplied into each column of the rotation submatrix before translation is written to column 3.

Matrix Operations

MathUtils.multiply(a, b)

Multiplies two 4×4 column-major matrices and returns the product.

  • a (Float32Array):
    Left-hand 4×4 matrix (16 elements, column-major).
  • b (Float32Array):
    Right-hand 4×4 matrix (16 elements, column-major).
  • Returns: Float32Array
    A new 16-element Float32Array representing the product a × b in column-major order.

Behavior

  • Unrolls the inner loops for performance — each element of the output is computed with an explicit dot product of one row of a and one column of b.
  • Allocates a new output buffer; does not mutate either input matrix.

Note

This implements standard matrix multiplication where the vector convention is column vectors. In this convention, multiply(a, b) applies transform a first, then b in a transformation pipeline (v' = a × b × v, meaning b is applied first to the vertex).

Vector Transformations

MathUtils.transformPos(v, m)

Transforms a 3D position vector by a 4×4 matrix, applying perspective division.

  • v (number[] | [number, number, number]):
    The position vector [x, y, z] to transform.
  • m (Float32Array):
    A 16-element column-major 4×4 transformation matrix.
  • Returns: [number, number, number]
    The transformed position as a 3-element array.

Formula

w = m[3]*x + m[7]*y + m[11]*z + m[15]
x' = (m[0]*x + m[4]*y + m[8]*z + m[12]) / w
y' = (m[1]*x + m[5]*y + m[9]*z + m[13]) / w
z' = (m[2]*x + m[6]*y + m[10]*z + m[14]) / w

If w is 0, it is clamped to 1.0 to avoid division by zero. This handles pure affine matrices (where m[15] is 1 and the bottom row is [0,0,0,1]) without unnecessary perspective division.

MathUtils.transformNorm(v, m)

Transforms a 3D normal vector by the inverse transpose of a 4×4 matrix (derived by using only the upper-left 3×3 submatrix), preserving orthogonality for non-uniform scales.

  • v (number[] | [number, number, number]):
    The normal vector [x, y, z] to transform.
  • m (Float32Array):
    A 16-element column-major 4×4 transformation matrix. Only the upper-left 3×3 rotation/scale submatrix is used.
  • Returns: [number, number, number]
    The transformed normal as a 3-element array (not renormalized).

Formula

x' = m[0]*x + m[4]*y + m[8]*z
y' = m[1]*x + m[5]*y + m[9]*z
z' = m[2]*x + m[6]*y + m[10]*z

This uses the correct normal transformation for affine matrices where the upper-left 3×3 represents the rotation and scale. Translation components (columns 3 and 4) are omitted since normals are direction vectors unaffected by translation.

Interpolation Functions

MathUtils.lerp(a, b, t, out, offset)

Performs linear interpolation between two 3-component vectors and writes the result directly into a pre-allocated Float32Array at a specified offset.

  • a (number[]):
    The start vector [x, y, z] (at t = 0).
  • b (number[]):
    The end vector [x, y, z] (at t = 1).
  • t (number):
    Interpolation factor in the range [0, 1]. Values outside this range produce extrapolation.
  • out (Float32Array):
    The pre-allocated output array to write results into.
  • offset (number):
    The starting index in the output array where the interpolated values are written. Writes 3 consecutive floats at offset, offset+1, and offset+2.
  • Returns: void

Formula

out[offset + i] = a[i] + t × (b[i] - a[i])  // for i = 0, 1, 2

Performance Note

Writes directly into the output buffer at the given offset, avoiding intermediate allocations. This is critical for per-frame animation evaluation where minimizing garbage collection pressure is essential.

MathUtils.slerp(a, b, t, out, offset)

Performs spherical linear interpolation between two quaternions and writes the result into a pre-allocated Float32Array at a specified offset.

  • a (number[]):
    The start quaternion [x, y, z, w] (at t = 0).
  • b (number[]):
    The end quaternion [x, y, z, w] (at t = 1).
  • t (number):
    Interpolation factor in the range [0, 1].
  • out (Float32Array):
    The pre-allocated output array to write results into.
  • offset (number):
    The starting index in the output array where the interpolated quaternion is written. Writes 4 consecutive floats at offset through offset+3.
  • Returns: void

Algorithm

1. Shortest Path Selection

The dot product between quaternions a and b is computed. If negative, quaternion b is negated to ensure rotation takes the shortest arc on the 4D hypersphere. This prevents interpolation from going the "long way around."

2. Degenerate Case 1 — Quaternions Nearly Identical

If |cosHalfTheta| ≥ 1.0, the quaternions are effectively the same. Quaternion a is copied directly to the output to avoid division by zero.

3. Degenerate Case 2 — Angle Very Small

If sinHalfTheta < 0.001, the quaternions are very close. A fast linear approximation (Nlerp) is used:

out[offset + i] = 0.5 × a[i] + 0.5 × b[i]

This avoids numerical instability when sinHalfTheta approaches zero.

4. Standard Slerp

For non-degenerate cases, the standard spherical interpolation formula is used:

out = (sin((1-t) × θ) / sin(θ)) × a + (sin(t × θ) / sin(θ)) × b

Where θ = acos(|cosHalfTheta|).

Memory Allocation Strategy

Method Allocation Notes
identity() New Float32Array Each call allocates a fresh buffer
multiply() New Float32Array Each call allocates a fresh output
fromTRS() New Float32Array Each call allocates a fresh buffer
transformPos() New number[] (3 elements) Small allocation per call
transformNorm() New number[] (3 elements) Small allocation per call
lerp() None Writes into caller-provided buffer at offset
slerp() None Writes into caller-provided buffer at offset

The interpolation functions (lerp and slerp) are specifically designed to be allocation-free, writing directly into pre-allocated typed arrays with an offset parameter. This is critical for the Animator class, which evaluates dozens of animation channels per frame without creating garbage.

Typical Workflow

import { MathUtils } from './MathUtils';

// Build a transformation matrix
const translation = [1.0, 2.0, 3.0];
const rotation = [0.0, 0.0, 0.0, 1.0]; // Identity quaternion
const scale = [2.0, 2.0, 2.0];
const worldMatrix = MathUtils.fromTRS(translation, rotation, scale);

// Multiply matrices
const parentMatrix = MathUtils.identity();
const combined = MathUtils.multiply(parentMatrix, worldMatrix);

// Transform a vertex
const localPos = [1, 0, 0];
const localNormal = [0, 1, 0];
const worldPos = MathUtils.transformPos(localPos, combined);
const worldNormal = MathUtils.transformNorm(localNormal, combined);

// Interpolate animation values (allocation-free)
const localTranslations = new Float32Array(100 * 3); // Pre-allocated
MathUtils.lerp([0,0,0], [10,0,0], 0.5, localTranslations, 5 * 3);

const localRotations = new Float32Array(100 * 4); // Pre-allocated
MathUtils.slerp([0,0,0,1], [0,1,0,0], 0.5, localRotations, 5 * 4);
