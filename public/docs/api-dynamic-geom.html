The Geometry, GeometryBuilder, VertexLayout, Primitives, MegabufferBuilder, and DynamicGeometryManager systems provide NullGraph’s core geometry pipeline. Together they define vertex memory layouts, procedural mesh generation, GPU upload workflows, megabuffer packing, and dynamic runtime geometry streaming.

VertexAttribute (Enum)

Defines the supported vertex attribute types used when constructing a VertexLayout.

  • Position
    float32x3 (12 bytes) — Vertex world/local position.
    • ```
  • Normal
    float32x3 (12 bytes) — Vertex normal vector.
  • UV
    float32x2 (8 bytes) — Texture coordinate.
  • Color
    float32x4 (16 bytes) — RGBA vertex color.
    • ```

VertexLayout (Class)

Represents a fully-defined vertex memory layout. This class calculates stride information automatically and generates the WebGPU-compatible vertex buffer descriptors required by render pipelines.

Constructor

new VertexLayout(attributes)

  • attributes (VertexAttribute[]): Ordered list of vertex attributes.

Public Properties

  • attributes: VertexAttribute[]
    Ordered list describing the structure of each vertex.
    • ```
  • strideBytes: number
    Total vertex size in bytes.
  • strideFloats: number
    Total vertex size in 32-bit floats.
    • ```

Methods

getWebGPUDescriptor()

Generates the exact GPUVertexBufferLayout[] descriptor required by device.createRenderPipeline().

  • Returns: GPUVertexBufferLayout[]

Built-in Layouts

  • CompleteLayout
    Includes Position + Normal + UV + Color.
    • ```
  • StandardLayout
    Includes Position + Normal + UV.
  • PositionOnlyLayout
    Includes only Position.
    • ```

Geometry (Class)

Represents a CPU-side mesh and its corresponding GPU buffers. Geometry objects store raw vertex/index data and can upload themselves directly to GPU memory using the engine’s BufferManager.

Constructor

new Geometry(layout, vertices, indices)

  • layout (VertexLayout): Vertex memory layout.
  • vertices (Float32Array): Raw vertex data.
  • indices (Uint16Array | Uint32Array): Triangle index data.

Public Properties

  • layout: VertexLayout
    The vertex layout used by this mesh.
    • ```
  • vertices: Float32Array
    Raw CPU-side vertex array.
  • indices: Uint16Array | Uint32Array
    Raw CPU-side index array.
  • vertexBuffer: GPUBuffer | null
    GPU vertex buffer generated after upload.
  • indexBuffer: GPUBuffer | null
    GPU index buffer generated after upload.
    • ```

Methods

upload(engine)

Uploads the mesh to GPU memory using the engine’s BufferManager.

  • engine (NullGraph): Active engine instance.
  • Returns: void

destroy()

Destroys the underlying GPU buffers and clears internal references.

  • Returns: void

VertexData (Interface)

Describes a single vertex used by GeometryBuilder.

  • position: [number, number, number]
    Required XYZ vertex position.
    • ```
  • normal?: [number, number, number]
    Optional vertex normal.
  • uv?: [number, number]
    Optional texture coordinates.
  • color?: [number, number, number, number]
    Optional RGBA vertex color.
    • ```

GeometryBuilder (Class)

Utility for manually constructing procedural meshes vertex-by-vertex at runtime.

Constructor

new GeometryBuilder(layout)

  • layout (VertexLayout): Vertex format definition.

Public Properties

  • vertices: number[]
    Accumulated vertex data.
    • ```
  • indices: number[]
    Accumulated index data.
    • ```

Methods

addVertex(data)

Adds a vertex to the geometry stream.

  • data (VertexData): Vertex definition.
  • Returns: number — The generated vertex index.

addTriangle(a, b, c)

Adds a triangle face using existing vertex indices.

build()

  • Returns: { v: Float32Array; i: Uint16Array; vertexBuffer: Float32Array; indexBuffer: Uint16Array; layout: VertexLayout; }

MeshOffset (Interface)

Describes where a mesh exists inside a packed megabuffer.

  • indexCount: number
    Total indices belonging to the mesh.
    • ```
  • firstIndex: number
    Starting index inside the global index buffer.
  • baseVertex: number
    Starting vertex inside the global vertex buffer.
  • meshID: number
    Unique integer ID useful for GPU-driven rendering systems.
  • vertexCount?: number
    Optional total vertex count.
    • ```

MegabufferBuilder (Class)

Utility for combining multiple meshes into one giant packed vertex/index buffer pair for GPU-efficient rendering.

Constructor

new MegabufferBuilder(vertexStrideFloats?)

  • vertexStrideFloats (number): Floats per vertex. Defaults to 6.

Methods

addMesh(name, meshVertices, meshIndices)

Packs a mesh into the megabuffer and returns its offsets.

  • name (string): Mesh registry name.
  • meshVertices (Float32Array | number[])
  • meshIndices (Uint16Array | number[])
  • Returns: MeshOffset

build()

Builds the final packed vertex/index arrays.

  • Returns: { megaVertices: Float32Array; megaIndices: Uint16Array | Uint32Array; indexFormat: GPUIndexFormat; }

getOffset(name)

Retrieves the stored offset information for a mesh.

  • name (string)
  • Returns: MeshOffset

DynamicGeometryManager (Class)

Manages large shared GPU geometry buffers with runtime allocation and deallocation support. Useful for streaming chunks, procedural terrain, voxel worlds, or dynamically generated meshes.

Constructor

new DynamicGeometryManager(device, maxVertices, maxIndices, vertexStrideFloats?)

  • device (GPUDevice)
  • maxVertices (number)
  • maxIndices (number)
  • vertexStrideFloats (number): Defaults to 6.

Public Properties

  • vbo: GPUBuffer
    Shared dynamic vertex buffer.
    • ```
  • ibo: GPUBuffer
    Shared dynamic index buffer.
    • ```

Methods

addMesh(name, meshVertices, meshIndices)

Allocates space in the shared buffers and uploads geometry data directly to the GPU.

  • name (string)
  • meshVertices (Float32Array)
  • meshIndices (Uint16Array | Uint32Array)
  • Returns: MeshOffset

removeMesh(name)

Removes a mesh and returns its memory blocks back to the allocator’s free lists.

  • name (string)
  • Returns: void

getOffset(name)

Retrieves the offset information for a registered mesh.

  • name (string)
  • Returns: MeshOffset

Implementation Note: DynamicGeometryManager.removeMesh() currently requires vertexCount to be tracked in MeshOffset for proper vertex memory reclamation. Without it, only partial free-list recovery is possible.
