The Primitives class provides procedural mesh generation utilities for creating common geometric shapes compatible with NullGraph's Geometry and VertexLayout systems.

Primitives (Class)

A static utility class for generating prebuilt procedural geometry meshes.

Each primitive dynamically adapts its vertex data output based on the provided VertexLayout, meaning only requested attributes are written into the vertex stream.

Supported Vertex Attributes

All primitive generators support the following attributes dynamically:

  • Position
  • Normal
  • UV
  • Color

Color Behavior

If the layout requests a Color attribute, generated vertices default to solid white:

[1.0, 1.0, 1.0, 1.0]

Normal Generation

Several primitives compute face normals dynamically using the cross product of triangle edges.

The generated normal is normalized before storage:

\vec{n}=\frac{(v_1-v_0)\times(v_2-v_0)}{\left|(v_1-v_0)\times(v_2-v_0)\right|}

Common Characteristics

  • All primitives are centered at the origin (0,0,0).
  • All geometry is generated using Counter-Clockwise (CCW) winding order.
  • Layouts dynamically control which vertex attributes are emitted.
  • Generated meshes return fully constructed Geometry instances.

Usage Example

const cube = Primitives.createCube(
    StandardLayout,
    1,
    1,
    1
);

cube.upload(engine);

The resulting geometry can be bound directly into a render batch or rendering pipeline.
