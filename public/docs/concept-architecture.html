The NullGraph Engine is a WebGPU-based real-time 3D rendering engine designed around a data-oriented, pass-and-batch architecture. It provides PBR rendering, skeletal animation, GLB model loading, GPU profiling, and on-screen performance monitoring — all orchestrated through a central NullGraph engine class that ties together subsystems for rendering, resource management, and frame execution.

Core Engine: NullGraph Class

The NullGraph class is the central orchestrator and public API surface. It owns all subsystem instances and exposes convenience methods that delegate to those subsystems.

Subsystem Ownership

Subsystem Property Role
WebGPUContext ctx Device, canvas context, swap chain format, camera uniform buffer, shared depth texture
BatchManager batchManager Batch creation, pipeline construction, bind group assembly, batch cleanup
RenderPipeline renderPipeline Pass execution, indirect draw reset, compute culling dispatch, GPU submission
BufferManager bufferManager Vertex and index buffer creation from CPU data
TextureManager textureManager Fallback textures (white, normal), default sampler, texture loading

Public API Surface

init(canvas)

Boots the engine: configures the WebGPU device with required features ('timestamp-query', etc.), creates the canvas context, allocates the camera uniform buffer and shared depth texture, instantiates all subsystems, and prepares the engine for rendering.

createPass(config)

Creates a new RenderPassNode. Delegates to the RenderPassNode constructor. Returns the pass for batch attachment.

createBatch(pass, config)

Creates a fully configured RenderBatch and adds it to the specified pass. Delegates to BatchManager.createBatch().

updateCamera(camera)

Writes the camera's view-projection matrix and eye position to the GPU camera uniform buffer. Called every frame before rendering.

render()

Executes a full frame: delegates to RenderPipeline.render(passes), which encodes all passes and submits the command buffer to the GPU queue.

Convenience Delegates

  • setBatchGeometry(batch, vbo, ibo, indexCount, format?) → BatchManager.setBatchGeometry()
  • updateBatchData(batch, data, count) → BatchManager.updateBatchData()
  • attachTextureMaterial(batch, views, sampler, extras?, group?) → BatchManager.attachTextureMaterial()
  • attachMaterial(batch, material, group?) → BatchManager.attachMaterial()
  • clearBatch(pass, batch) → BatchManager.clearBatch()

Frame Execution Pipeline

Each frame follows a strict execution sequence:


                   APPLICATION FRAME LOOP
═══════════════════════════════════════════════════════════════

  1. Input / Logic Update
     │
     ├── Update game state, animation timers
     │
     ▼
  2. Camera Update
     │
     ├── camera.updateView(eye, target)
     ├── engine.updateCamera(camera)
     │   └── Writes {viewProj, eyePos, simTime} to GPU uniform buffer
     │
     ▼
  3. Animation Evaluation (if skinned meshes present)
     │
     ├── animator.update(deltaTime)
     ├── skeletonManager.updateFromAnimator(device, animator)
     │   └── Uploads skinning matrices to GPU uniform buffer
     │
     ▼
  4. Instance Data Upload
     │
     ├── engine.updateBatchData(batch, instanceData, count)
     │   └── Writes per-instance transforms to storage buffer
     │
     ▼
  5. GPU Profiling (optional)
     │
     ├── gpuProfiler.begin()
     │
     ▼
  6. Render Submission
     │
     ├── engine.render()
     │   │
     │   └── RenderPipeline.render(passes)
     │       │
     │       ├── For each RenderPassNode:
     │       │   ├── Phase 1: Indirect draw reset (zero instance count)
     │       │   ├── Phase 2: Compute culling dispatch
     │       │   ├── Phase 3: Attachment resolution (canvas or offscreen)
     │       │   └── Phase 4: Draw batch execution
     │       │
     │       └── device.queue.submit([commandEncoder.finish()])
     │
     ▼
  7. GPU Profiling (optional)
     │
     ├── gpuProfiler.end((gpuMs) => { ... })
     │
     ▼
  8. Performance Widget Update
     │
     ├── perfWidget.tick()          // FPS counter
     └── perfWidget.updateMetrics() // CPU/GPU times (when GPU data arrives)

Data Flow: From GLB to Screen

The complete data pipeline for rendering a skinned, PBR-textured 3D model:


  GLB FILE (.glb)
  ═══════════════
  │
  ▼
  GLBParser.load(url)
  │
  ├── Parses JSON chunk → glTF scene descriptor
  ├── Parses binary chunk → vertex data, index data, animation keyframes
  ├── Resolves image URLs → PNG/JPEG blob URLs
  │
  ▼
  GLBData
  ├── meshes: RawGeometryData[]
  │   ├── vertices: Float32Array (interleaved, dynamic stride)
  │   ├── indices: Uint16Array | Uint32Array
  │   ├── isSkinned: boolean
  │   ├── albedoUrl, normalUrl, metallicRoughnessUrl, etc.
  │   └── getWebGPULayout(): GPUVertexBufferLayout[]
  ├── skin: GLBSkin | null
  │   ├── joints: number[]
  │   ├── inverseBindMatrices: Float32Array
  │   └── nodes: glTF node array
  └── animations: GLBAnimation[]
      ├── channels: {targetNode, path, samplerIndex}[]
      ├── samplers: {input: times, output: values, interpolation}[]
      └── maxTime: number
  │
  ▼
  CPU-SIDE PROCESSING
  ═══════════════════
  │
  ├── BufferManager.createVertexBuffer(vertices) → GPUBuffer (VBO)
  ├── BufferManager.createIndexBuffer(indices)   → GPUBuffer (IBO)
  │
  ├── [If skinned] Animator(skin)
  │   └── Allocates local/global/skinning matrix arrays
  │
  ├── [If skinned] SkeletonManager(device, maxBones=70)
  │   └── Allocates GPU uniform buffer for bone matrices
  │
  ├── Texture loading (from resolved URLs)
  │   └── Creates GPUTexture + GPUTextureView for each map
  │
  ├── StandardPBRMaterial(engine, options)
  │   └── Allocates GPU uniform buffer for material params
  │
  ├── buildPBRShader({ useSkinning: true/false })
  │   └── Generates WGSL string with correct bindings
  │
  ▼
  BATCH CREATION (BatchManager.createBatch)
  ═════════════════════════════════════════
  │
  ├── Creates GPURenderPipeline (from shader + vertex layout)
  ├── Allocates storage buffer (instance transforms)
  ├── [If indirect] Allocates indirect buffer + compute pipeline
  ├── Creates bind group 0: camera uniform + storage buffer
  ├── [If material] Attaches material bind group 1
  │
  ▼
  PER-FRAME GPU UPLOAD
  ════════════════════
  │
  ├── Camera uniforms → GPU (viewProj, eyePos, simTime)
  ├── Skinning matrices → GPU (from Animator via SkeletonManager)
  ├── Instance data → GPU storage buffer
  │
  ▼
  GPU RENDERING (RenderPipeline.render)
  ═════════════════════════════════════
  │
  ├── [If indirect] Compute culling shader
  │   └── Tests each instance, writes survivors to indirect buffer
  │
  ├── Vertex Shader (vs_main)
  │   ├── Fetch ECS transform from storage buffer
  │   ├── [If skinned] Apply bone matrices + blend weights
  │   ├── Apply scale, rotation (quaternion), translation
  │   └── Output: clipPos, worldPos, worldNormal, uv
  │
  ├── Fragment Shader (fs_main)
  │   ├── Sample albedo, normal, packed (ORM) textures
  │   ├── Decode normal from map (TBN transform)
  │   ├── PBR Lighting: GGX distribution, Smith geometry, Schlick Fresnel
  │   ├── Ambient + directional light accumulation
  │   └── Output: tonemapped + gamma-corrected color
  │
  ▼
  HTML CANVAS
  ═══════════
  Final composited frame presented to screen

Per-Instance ECS Layout (14 floats / 56 bytes)

Offset (floats) Offset (bytes) Field Type
0 0 Padding / Reserved f32
1–3 4–12 World Position (xyz) vec3<f32>
4–7 16–28 World Rotation Quaternion (xyzw) vec4<f32>
8–10 32–40 World Scale (xyz) vec3<f32>
11–13 44–52 Padding / Reserved f32 × 3

The vertex shader accesses this with:

let base = iIdx * 14u;
let ecsPos = vec3<f32>(ecs[base + 1u], ecs[base + 2u], ecs[base + 3u]);
let ecsRot = vec4<f32>(ecs[base + 4u], ecs[base + 5u], ecs[base + 6u], ecs[base + 7u]);
let ecsScale = vec3<f32>(ecs[base + 8u], ecs[base + 9u], ecs[base + 10u]);

Offset (bytes) Field Type

Bind Group Layout Convention

The engine uses a fixed bind group layout convention across all PBR shaders:

Group Binding Resource Type Scope
@group(0) 0 Camera Uniform Per-frame (shared across all batches)
1 ECS Instance Data Storage (read) Per-batch
@group(1) 0 Sampler Sampler Per-material
1 Albedo Texture Texture 2D Per-material
2 Normal Texture Texture 2D Per-material
3 Packed ORM Texture Texture 2D Per-material
4 Material Params Uniform Per-material
@group(2) 0 Skeleton Bone Matrices Uniform Per-skinned-mesh (only if useSkinning)

Key Design Principles

  1. Pass-and-Batch Architecture: All rendering is organized into named render passes, each containing ordered batches. This maps directly to WebGPU's command encoding model and facilitates multi-pass rendering (shadow maps, G-buffers, post-processing).
  2. Data-Oriented Instancing: Instance transforms are stored in GPU storage buffers, not uniform arrays. This enables large instance counts (thousands) with a single draw call and supports GPU-driven culling via compute shaders.
  3. Dynamic Shader Generation: Shaders are assembled at runtime from composable WGSL chunks based on material configuration (static vs. skinned, texture formats). This avoids shader permutation explosion while maintaining flexibility.
  4. Automatic Pipeline Layout: The engine uses layout: 'auto' for pipeline creation, allowing WebGPU to derive bind group layouts from shader reflection. This eliminates manual layout management while ensuring type safety.
  5. Allocation-Conscious Animation: The Animator pre-allocates all typed arrays at construction and writes interpolation results into existing buffers at offsets — producing zero garbage during animation evaluation.
  6. Asynchronous GPU Readback: The GPUProfiler uses non-blocking mapAsync with a guard flag to prevent overlapping measurements, ensuring the CPU never stalls waiting for GPU timestamps.
  7. Self-Contained UI: The PerformanceWidget self-injects its CSS and HTML, requiring no external stylesheets or markup. It supports both mouse and touch dragging for repositioning.
  8. Consistent Coordinate Convention: Column-major matrices, right-handed coordinate system, quaternion rotation (xyzw). The vertex shader applies transforms in TRS order: Scale → Rotate → Translate.

Minimal Application Template

import { NullGraph, Camera } from 'null-graph';
import { Primitives, StandardLayout } from 'null-graph/geometry';
import { buildPBRShader, StandardPBRMaterial } from 'null-graph/materials';

async function main() {
    // 1. Initialize engine
    const canvas = document.getElementById('gpuCanvas');
    const engine = new NullGraph();
    await engine.init(canvas);

    // 2. Create camera
    const camera = new Camera(75, canvas.width / canvas.height, 0.1, 1000.0);

    // 3. Create render pass
    const mainPass = engine.createPass({ name: 'Main', isMainScreenPass: true });

    // 4. Create geometry
    const geom = Primitives.createCube(StandardLayout, 2, 2, 2);
    geom.upload(engine);

    // 5. Create material
    const material = new StandardPBRMaterial(engine, {
        baseColor: [0.1, 0.5, 0.9, 1.0],
        metallicMultiplier: 0.2,
        roughnessMultiplier: 0.5
    });

    // 6. Create batch
    const batch = engine.createBatch(mainPass, {
        shaderCode: buildPBRShader({ useSkinning: false }),
        strideFloats: 14,
        maxInstances: 1,
        vertexLayouts: geom.layout.getWebGPUDescriptor(),
        depthWriteEnabled: true
    });

    // 7. Attach material and geometry
    material.applyToBatch(batch);
    engine.setBatchGeometry(batch, geom.vertexBuffer, geom.indexBuffer, geom.indices.length);

    // 8. Set instance data
    const instanceData = new Float32Array([
        0, 0, 0, 0,   // padding + position xyz
        0, 0, 0, 1,   // rotation xyzw
        1, 1, 1,      // scale xyz
        1, 1, 1       // reserved
    ]);
    engine.updateBatchData(batch, instanceData, 1);

    // 9. Render loop
    function frame() {
        camera.updateView(
            [Math.sin(performance.now() * 0.001) * 8, 3, Math.cos(performance.now() * 0.001) * 8],
            [0, 0, 0]
        );
        engine.updateCamera(camera);
        engine.render();
        requestAnimationFrame(frame);
    }

    frame();
}

main();
