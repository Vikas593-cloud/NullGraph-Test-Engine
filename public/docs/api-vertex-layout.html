The VertexLayout system defines how vertex data is structured in memory and translated into WebGPU-compatible vertex buffer layouts. It provides reusable attribute presets and automatic stride calculation for rendering pipelines.

VertexAttribute (Enum)

Defines the supported vertex attributes that can be included in a vertex layout.

Values

  • Position
    3D position attribute.
    Format: float32x3
    Size: 12 bytes
    • ```
  • Normal
    Vertex normal vector.
    Format: float32x3
    Size: 12 bytes
  • UV
    Texture coordinate attribute.
    Format: float32x2
    Size: 8 bytes
  • Color
    Vertex color attribute.
    Format: float32x4
    Size: 16 bytes
    • ```

VertexLayout (Class)

Represents a complete vertex buffer memory layout used when configuring WebGPU render pipelines.

The class automatically calculates byte stride, float stride, and generates the corresponding GPUVertexBufferLayout descriptor.

Constructor

new VertexLayout(attributes)

Creates a new vertex layout using the provided ordered attribute list.

  • attributes (VertexAttribute[]):
    Ordered list of vertex attributes defining the memory layout.

Behavior

  • Automatically calculates total vertex stride in bytes and floats.
  • Attribute order determines:
    • Memory offsets
    • Shader locations
    • Final vertex layout structure

Public Properties

  • attributes: VertexAttribute[]
    Ordered list of attributes included in this layout.
    • ```
  • strideBytes: number
    Total vertex size in bytes.
  • strideFloats: number
    Total vertex size expressed as 32-bit floats.
    Useful for engine-side buffer allocation and CPU-side packing logic.
    • ```

WebGPU Descriptor Generation

getWebGPUDescriptor()

Generates the exact GPUVertexBufferLayout[] descriptor required by device.createRenderPipeline().

  • Returns: GPUVertexBufferLayout[]

Behavior

  • Automatically assigns sequential shader locations starting at 0.
  • Calculates byte offsets for each attribute.
  • Maps engine attributes to their matching WebGPU formats.
  • Produces a single interleaved vertex buffer layout.

Built-in Layout Presets

CompleteLayout

A fully featured layout containing:

  • Position
  • Normal
  • UV
  • Color

Structure

  • Total Stride: 48 bytes
  • Total Floats: 12

StandardLayout

A standard mesh layout containing:

  • Position
  • Normal
  • UV

Structure

  • Total Stride: 32 bytes
  • Total Floats: 8

PositionOnlyLayout

A minimal layout containing only vertex positions.

  • Position

Structure

  • Total Stride: 12 bytes
  • Total Floats: 3

Usage Example

const layout = new VertexLayout([
    VertexAttribute.Position,
    VertexAttribute.Normal,
    VertexAttribute.UV
]);

const descriptor = layout.getWebGPUDescriptor();

The generated descriptor can then be passed directly into a WebGPU render pipeline configuration.
