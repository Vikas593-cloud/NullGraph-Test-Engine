This guide walks through creating your first rendered object in NullGraph using the engine's Render Batch architecture, built-in geometry generators, and PBR material system.

Overview

The Quick Start pipeline follows these core steps:

  1. Initialize the NullGraph engine and size the canvas.
  2. Create a primary screen render pass.
  3. Generate cube geometry using the built-in primitive system.
  4. Create a PBR material using fallback textures.
  5. Create and configure a Render Batch.
  6. Define and upload Data-Oriented instance data (ECS Layout) to the GPU.
  7. Initialize the Camera system.
  8. Start the dynamic render loop.

Imports

Import the core engine, camera, geometry utilities, and material system.


import { NullGraph, Camera } from 'null-graph';
import { Primitives, StandardLayout } from 'null-graph/geometry';
import { buildPBRShader, StandardPBRMaterial } from 'null-graph/materials';

Engine Initialization

new NullGraph()

Creates a new engine instance. It is best practice to handle canvas sizing dynamically before initializing the engine.


const canvas = document.getElementById('gpuCanvas') as HTMLCanvasElement;
canvas.width = canvas.clientWidth || 800;
canvas.height = Math.max(1, canvas.clientHeight || 600);

const engine = new NullGraph();
await engine.init(canvas);

Creating a Render Pass

Creates the main render pass responsible for presenting graphics to the screen.


const mainPass = engine.createPass({
    name: 'Main',
    isMainScreenPass: true
});

Generating Geometry

Generates cube geometry using the engine's built-in geometry system and uploads the vertex/index data directly to GPU memory.


const cubeGeom = Primitives.createCube(StandardLayout, 2, 2, 2);
cubeGeom.upload(engine);

Creating a PBR Material

Creates a physically based material using the Cook-Torrance BRDF pipeline. Here, we use fallback textures provided by the engine's texture manager.


const material = new StandardPBRMaterial(engine, {
    albedoMap: engine.textureManager.fallbackWhite,
    normalMap: engine.textureManager.fallbackNormal,
    packedMap: engine.textureManager.fallbackWhite,
    packedMapFormat: "ARM",
    baseColor: [0.1, 0.5, 0.9, 1.0],
    metallicMultiplier: 0.2,
    roughnessMultiplier: 0.5
});

Creating a Render Batch & Binding

A Render Batch is the GPU rendering workload. After creating it, we bind our material and geometry buffers to it.


const cubeBatch = engine.createBatch(mainPass, {
    shaderCode: buildPBRShader({ useSkinning: false }),
    strideFloats: 14,
    maxInstances: 1,
    vertexLayouts: cubeGeom.layout.getWebGPUDescriptor(),
    depthWriteEnabled: true
});

// Bind materials and geometry
material.applyToBatch(cubeBatch);
engine.setBatchGeometry(
    cubeBatch,
    cubeGeom.vertexBuffer!,
    cubeGeom.indexBuffer!,
    cubeGeom.indices.length
);

Instance Data Layout (Data-Oriented ECS)

NullGraph uses a flat, Data-Oriented approach for entity data rather than heavy JavaScript objects. We use a single Float32Array mapped to a 14-float stride per instance. This translates directly to the GPU buffer.

Indices Component Description
[0, 1, 2] Position X, Y, Z coordinates in world space.
[3, 4, 5, 6] Rotation Quaternion X, Y, Z, W for 3D rotation.
[7, 8, 9] Scale X, Y, Z local scale multipliers (Defaults to 1.0).
[10, 11, 12, 13] Color / Tint R, G, B, A multipliers (Defaults to 1.0).

engine.updateBatchData()

Uploads this flat instance array directly into the batch storage buffer.


const initialData = new Float32Array(14);

// Set Scale (indices 7, 8, 9) to 1.0
initialData[7] = 1.0;
initialData[8] = 1.0;
initialData[9] = 1.0;

// Set RGBA Tint (indices 10, 11, 12, 13) to 1.0
initialData[10] = 1.0;
initialData[11] = 1.0;
initialData[12] = 1.0;
initialData[13] = 1.0;

engine.updateBatchData(cubeBatch, initialData, 1);

Camera & Render Loop

NullGraph requires a Camera to calculate the view and projection matrices. In the render loop, we calculate simulated time to dynamically orbit the camera around the cube.


// Initialize Camera: FOV, Aspect Ratio, Near Plane, Far Plane
const camera = new Camera(75, canvas.width / canvas.height, 0.1, 1000.0);

function frame() {
    // Safety check to ensure engine wasn't destroyed during hot-reloads
    if (!engine.isDestroyed) {

        // Calculate dynamic orbit based on time
        const simTime = performance.now() * 0.001;
        camera.updateView(
            [Math.sin(simTime) * 6, 3, Math.cos(simTime) * 6], // Eye Position
            [0, 0, 0]                                          // Target Position
        );

        // Push camera updates to the GPU and render
        engine.updateCamera(camera);
        engine.render();

        requestAnimationFrame(frame);
    }
}

frame();

Complete Example


import { NullGraph, Camera } from 'null-graph';
import { Primitives, StandardLayout } from "null-graph/geometry";
import { buildPBRShader, StandardPBRMaterial } from "null-graph/materials";

async function main() {
    const canvas = document.getElementById('gpuCanvas') as HTMLCanvasElement;
    canvas.width = canvas.clientWidth || 800;
    canvas.height = Math.max(1, canvas.clientHeight || 600);

    const engine = new NullGraph();
    await engine.init(canvas);

    const mainPass = engine.createPass({ name: 'Main', isMainScreenPass: true });

    const cubeGeom = Primitives.createCube(StandardLayout, 2, 2, 2);
    cubeGeom.upload(engine);

    const material = new StandardPBRMaterial(engine, {
        albedoMap: engine.textureManager.fallbackWhite,
        normalMap: engine.textureManager.fallbackNormal,
        packedMap: engine.textureManager.fallbackWhite,
        packedMapFormat: "ARM",
        baseColor: [0.1, 0.5, 0.9, 1.0],
        metallicMultiplier: 0.2,
        roughnessMultiplier: 0.5
    });

    const cubeBatch = engine.createBatch(mainPass, {
        shaderCode: buildPBRShader({ useSkinning: false }),
        strideFloats: 14,
        maxInstances: 1,
        vertexLayouts: cubeGeom.layout.getWebGPUDescriptor(),
        depthWriteEnabled: true
    });

    material.applyToBatch(cubeBatch);
    engine.setBatchGeometry(cubeBatch, cubeGeom.vertexBuffer!, cubeGeom.indexBuffer!, cubeGeom.indices.length);

    const initialData = new Float32Array(14);
    initialData[7] = 1.0;  // Scale X
    initialData[8] = 1.0;  // Scale Y
    initialData[9] = 1.0;  // Scale Z
    initialData[10] = 1.0; // Color R
    initialData[11] = 1.0; // Color G
    initialData[12] = 1.0; // Color B
    initialData[13] = 1.0; // Color A
    engine.updateBatchData(cubeBatch, initialData, 1);

    const camera = new Camera(75, canvas.width / canvas.height, 0.1, 1000.0);

    function frame() {
        if (!engine.isDestroyed) {
            const simTime = performance.now() * 0.001;
            camera.updateView([Math.sin(simTime) * 6, 3, Math.cos(simTime) * 6], [0, 0, 0]);
            engine.updateCamera(camera);
            engine.render();
            requestAnimationFrame(frame);
        }
    }

    frame();
}

main().catch(err => console.error("Engine Crash:", err));
